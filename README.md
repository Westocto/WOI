# WOI downloader

YouTube, Vimeo, Instagram, Facebook, X ve TikTok için Windows indirme uygulaması.

Bu depo yalnızca kurulum dosyalarını ve güncelleme bilgisini (`latest.json`) barındırır.
Kurulu uygulama yeni sürümleri buradan denetler ve kendini günceller.

- Son sürüm: `releases/<sürüm>/WOIdownloader_setup.exe`
- Kaldırma: `releases/<sürüm>/Uninstall.exe`
